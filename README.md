# TABAKBO — 기타 탭 악보 편집기

클릭 + 숫자 입력으로 프렛 번호를 넣는 방식의 기타 TAB 악보 편집기입니다. 표준 튜닝(EADGBE), 4/4박자·16분음표 그리드를 기준으로 하며, 브라우저에서만 동작하는 웹 앱입니다.

**[웹에서 열기](https://leeyohan-sys.github.io/tabakbo/)** — 별도 설치 없이 바로 사용 가능

- 모든 데이터는 브라우저 안에서만 처리되고 서버로 전송되지 않습니다.
- 저장/열기는 `tab.json` 파일 다운로드·업로드로 동작합니다.
- "이미지로 내보내기"는 화면에 보이는 악보(펜으로 그린 것 포함)를 그대로 PNG로 다운로드합니다.

## 사용법

1. 칸을 클릭해 선택한 뒤 위 입력창에 프렛 번호(0~24)를 입력 (모바일에서도 숫자 키패드로 입력 가능)
2. 값이 있는 칸을 마우스로 누른 채 다른 칸으로 드래그하면 그 위치로 옮겨짐
3. 뮤트 / 지우기 버튼으로 음소거·삭제, 방향키로 칸 이동 (데스크톱)
4. "마디 추가/삭제"로 길이 조절 (한 줄 = 4마디, 마디 삭제는 선택된 칸이 속한 줄 전체를 삭제)
5. "재생"으로 입력한 탭을 통기타 음색으로 들어보기
6. "펜"으로 악보 위에 자유롭게 그리기, "되돌리기"로 마지막 획만 취소
7. "저장/열기"는 JSON, "텍스트"는 클래식 ASCII 탭, "이미지"는 PNG로 내보내기 (저장 시 파일 이름을 직접 정할 수 있음)
