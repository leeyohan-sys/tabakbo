# TABAKBO — 기타 탭 악보 편집기

클릭 + 숫자 입력으로 프렛 번호를 넣는 방식의 기타 TAB 악보 편집기입니다. 표준 튜닝(EADGBE), 4/4박자·16분음표 그리드를 기준으로 합니다.

## 웹 버전

별도 설치 없이 브라우저에서 바로 사용할 수 있습니다: **[웹에서 열기](https://leeyohan-sys.github.io/tabakbo/)**

- 모든 데이터는 브라우저 안에서만 처리되고 서버로 전송되지 않습니다.
- 저장/열기는 `tab.json` 파일 다운로드·업로드로 동작합니다.
- "이미지로 내보내기"는 A4 가로폭(210mm)에 맞춰 4마디씩 자동 줄바꿈된 PNG를 다운로드합니다.

## 사용법

1. 칸을 클릭해 선택
2. 숫자(0~24)를 입력하면 프렛 번호가 그 줄 위에 표시됨 (두 자리는 빠르게 연속 입력)
3. `x` = 뮤트, `Delete`/`Backspace` = 지우기, 방향키로 이동
4. "마디 추가/삭제"로 길이 조절
5. "재생"으로 입력한 탭을 통기타 음색으로 들어보기
6. "저장/열기"는 JSON, "텍스트로 내보내기"는 클래식 ASCII 탭, "이미지로 내보내기"는 PNG

## 데스크톱 버전 (Windows)

Python + [pywebview](https://pywebview.flowrl.com/) 기반 데스크톱 앱도 포함되어 있습니다.

```
pip install -r requirements.txt   # 필요 시
run.bat
```

데스크톱 버전은 저장/열기/이미지 내보내기 시 파일 탐색기의 네이티브 저장 대화상자를 사용합니다.
